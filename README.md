# Portfólio Acadêmico & Médico — Marina Castello Branco Bastos

Portfólio acadêmico e acervo de publicações científicas de **Marina Castello Branco Bastos** (Departamento de Medicina, Universidade Federal de São João del Rei — UFSJ).

## Regras de Integridade Científica

1. **Apenas artigos reais**: Nenhum artigo fictício ou de exemplo é incluído no site. Todos os artigos exibidos vêm da pasta `artigos/`.
2. **Verificação dupla (PubMed + Crossref)**: Todas as referências bibliográficas são duplamente checadas pelo **PMID (PubMed)** e pelo **DOI (Crossref)** antes de entrarem no site.
3. **Acervo BibTeX (`referencias.bib`)**: Todas as referências verificadas são armazenadas no arquivo [`referencias.bib`](./referencias.bib).

## Publicação Automática no GitHub Pages

O arquivo [`.github/workflows/deploy-pages.yml`](./.github/workflows/deploy-pages.yml) está configurado para republicar automaticamente o site no **GitHub Pages** a cada `push` na branch `main` (ou `master`).

Para ativar no repositório do GitHub:
1. No GitHub, acesse **Settings → Pages** do repositório.
2. Em **Build and deployment → Source**, selecione **GitHub Actions**.
3. A cada novo `push`, o workflow publicará automaticamente a versão atualizada do site.
